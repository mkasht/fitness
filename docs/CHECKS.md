# Проверка первой рабочей версии

Исторический отчёт по этапам разработки. Команда для текущей проверки приведена в [README проекта](../README.md#проверки).

Проверено 6 ноября 2026 года.

- Сборка приложения успешна.
- Девять интеграционных тестов xUnit прошли на настоящем SQL Server LocalDB. Отдельная тестовая база создаётся с уникальным именем и удаляется после проверки.
- В браузере пройдена регистрация нового учебного пользователя.
- Выбрано занятие, заявка сохранена, число свободных мест уменьшилось.
- Заявка и уведомление появились в кабинете. После отмены изменился статус и освободилось место.
- Проверены вход менеджера, доступ к заявкам и запрет открытия каталога администратора.
- Проверены вход администратора и сохранение существующей услуги и профиля тренера.
- На ширине 360 пикселей проверены главная, каталог и запись; горизонтального переполнения страницы нет. Лента дат прокручивается внутри своего блока.
- Проверено раскрытие мобильного меню и его закрытие после перехода.
- На главной отображаются локальные изображения, созданные GPT Image.

На момент этой проверки редактор страниц, управление ролями и публичное размещение ещё были впереди.

## Исправление ресурсов упрощённого сайта после переноса

- Воспроизведена проблема старой Debug-сборки: при переносе без исходных каталогов запросы к CSS, изображениям и скриптам возвращали пустое тело даже со статусом 200.
- В проект добавлено копирование всех статических ресурсов SDK в выходную папку, включая CSS компонентов, Blazor и модуль восстановления соединения.
- Папка wwwroot определяется относительно исполняемого файла; добавлена выдача физических статических файлов.
- Исправленная сборка перенесена в отдельную папку. Проверка выполнялась в Production с посторонней рабочей папкой и намеренно недоступными исходными путями в служебном манифесте.
- Обычные и fingerprint-адреса CSS возвращают непустой text/css; изображения возвращают image/jpeg; скрипты возвращают text/javascript.
- В браузере проверены оформление, загрузка всех видимых изображений и интерактивный фильтр «Баланс» с двумя услугами.
- Новый архив исходников распакован в отдельную папку, восстановлен и собран без предупреждений и ошибок.
- Актуальный архив: .artifacts/Pulse-Lite-VisualStudio-fixed.zip. Основной архив Pulse-Lite-VisualStudio.zip также обновлён.
