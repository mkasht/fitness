# Пульс — проект для Visual Studio

В проекте три страницы: главная, «О клубе» и «Услуги». Данные карточек находятся в C#, изображения и стили хранятся в проекте. SQL Server не требуется.

## Запуск кнопкой «Старт»

1. Откройте `FitnessCenter.Lite.sln` в Visual Studio с поддержкой .NET 10.
2. Дождитесь загрузки проекта и восстановления зависимостей.
3. Нажмите зелёную кнопку «Старт» вверху окна или F5.
4. Браузер откроется по адресу http://localhost:5196/.
5. Для завершения нажмите «Остановить отладку» в Visual Studio.

Для разработки нужна нагрузка «ASP.NET и веб-разработка» и .NET 10 SDK. Если Visual Studio открывает выбор стартового проекта, выберите FitnessCenter.Lite. В этом решении только один запускаемый проект.

Если адрес уже занят ранее запущенной копией, сначала остановите её. Для запуска через Visual Studio файлы Start-Site.cmd и Start-Lite.ps1 не нужны.

## Перенос на другой компьютер

Склонируйте репозиторий или распакуйте ZIP с исходниками. Откройте `src/FitnessCenter.Lite/FitnessCenter.Lite.sln`, восстановите пакеты NuGet, затем нажмите «Старт» или F5. Для первого восстановления зависимостей нужен интернет.

При сборке в выходную папку автоматически копируются CSS, изображения, скрипты Blazor и стили компонентов. Приложение находит wwwroot рядом с исполняемым файлом и не зависит от рабочей папки запуска. После обновления перезагрузите страницу браузера сочетанием Ctrl+F5.

## Где находится CSS

В обозревателе решения есть отдельная папка CSS с прямыми ссылками на файлы:

- wwwroot/css/site.css — основные стили: цвета, шрифты, шапка, главная, каталог, карточки, подвал и адаптивность.
- Components/Layout/MainLayout.razor.css — оформление сообщения об ошибке.
- Components/Layout/ReconnectModal.razor.css — оформление восстановления соединения.

Основной CSS подключается в Components/App.razor. Файлы CSS отформатированы: правила и свойства записаны на отдельных строках.

## Где находятся страницы

- Components/Pages/Home.razor — главная.
- Components/Pages/About.razor — о клубе.
- Components/Pages/Services.razor — услуги.
- Components/Layout/MainLayout.razor — общая шапка и подвал.
- Components/Shared/ServiceCard.razor — карточка услуги.
- Data/ClubCatalog.cs — названия, описания, цены и изображения услуг.
- wwwroot/images — изображения GPT Image.

Для переноса исходников копируйте всю эту папку. Каталоги bin, obj и .vs можно не переносить: Visual Studio создаст их при сборке.
