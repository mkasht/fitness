ПУЛЬС — переносимая версия сайта

Для Windows 10/11 x64. Устанавливать .NET, SDK или базу данных не нужно.

1. Скопируйте ZIP-архив на другой компьютер.
2. Нажмите правой кнопкой по архиву и выберите «Извлечь всё».
3. Откройте извлечённую папку Pulse-Lite.
4. Дважды нажмите Start-Site.cmd.
5. Браузер откроется автоматически. Если этого не произошло,
   откройте в браузере http://localhost:5196/

Не закрывайте окно запуска, пока показываете сайт.
Чтобы остановить сайт, закройте окно запуска или нажмите Ctrl+C.

Переносите всю папку целиком. Рядом с приложением должны оставаться
папка wwwroot и остальные файлы: в них находятся картинки, оформление
и встроенная среда выполнения.

В этой версии три страницы: главная, о клубе и услуги.
Интернет для просмотра не требуется. Сайт открывается на том компьютере,
где запущен Start-Site.cmd.
